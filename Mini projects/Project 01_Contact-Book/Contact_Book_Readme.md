# 📒 Contact Book – Python Project

## 💡 Project Overview
This is a beginner level, menu driven Python project that demonstrates the practical use of dictionaries, functions, loops, and conditional statements to build a simple contact management system.

> **Note:** Contacts are currently stored in memory using a dictionary, so they are not permanently saved after the program exits.

---

## 🎯 Aim
The aim of this project is to create a simple Contact Book application using Python that allows users to manage their contacts by adding, searching, deleting, and displaying contact information.

---

## ⚙️ Features
1. **Add Contact:** Store a contact's name and phone number.
2. **Search Contact:** Find a contact using their name.
3. **Delete Contact:** Remove an existing contact.
4. **Show All Contacts:** Display all saved contacts alphabetically.
5. **Exit:** Close the application.

---

## 🛠️ Technologies Used
* **Language:** Python 3
* **Environment:** VS Code / Any Python IDE

---

## 🔑 Key Concepts Used
* **Dictionaries:** Used to store contact names as keys and phone numbers as values.
* **Functions:** Separate functions for adding, searching, deleting, and displaying contacts.
* **While Loop:** Keeps the application running until the user chooses to exit.
* **Conditional Statements (`if-elif-else`):** Used to handle user choices and check whether contacts exist.
* **For Loop:** Used to display all saved contacts.
* **Membership Operator (`in`):** Checks whether a contact exists in the dictionary.
* **Dictionary Methods:** Used dictionary operations to access, add, and delete contact information.
* **String Methods (`lower()`):** Makes the yes/no input check case-insensitive.
* **Sorting (`sorted()`):** Displays contact names in alphabetical order.
