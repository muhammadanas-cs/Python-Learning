# 🧮 Simple Calculator – Python Project

## 💡 Project Overview
This is a beginner friendly, command line Python project that performs basic arithmetic operations. It takes two numbers and an operation choice from the user and displays the calculated result.

## 🎯 Aim
The aim of this project is to build a functional calculator in Python to practice handling user input, performing mathematical operations, and applying conditional logic.

## ⚙️ Features
1. **Addition (`+`):** Adds two numbers.
2. **Subtraction (`-`):** Subtracts the second number from the first.
3. **Multiplication (`*`):** Multiplies two numbers.
4. **Division (`/`):** Divides the first number by the second (includes zero-division error handling).
5. **Exponential (`**`):** Raises the first number to the power of the second.
6. **Modulus (`%`):** Finds the remainder when the first number is divided by the second.

## 🛠️ Technologies Used
* **Language:** Python 3
* **Environment:** VS Code / Any Python IDE

## 🔑 Key Concepts Used
* **Functions (`def`):** Encapsulates the calculator logic inside a reusable `calculator()` function.
* **User Input (`input()`):** Captures the user's operation choice and numeric values.
* **Type Casting (`float()`):** Converts string inputs into floating-point numbers to support decimals.
* **Conditional Statements (`if-elif-else`):** Executes the selected mathematical operation and validates inputs.
* **Arithmetic Operators:** Uses `+`, `-`, `*`, `/`, `**`, and `%` for calculations.
* **Error Handling:** Prevents division by zero using a nested `if` condition.

## 📚 What I Learned
* How to take numerical input from users and convert data types using `float()`.
* How to structure basic menu options using `if-elif-else` statements.
* How to handle edge cases like division by zero (`num2 != 0`).
* How to use different arithmetic operators in Python.

## 🚀 How to Run
1. Make sure you have **Python 3** installed on your system.
2. Download or clone `Calculator.py`.
3. Open a terminal in the project folder and run:
   ```bash
   python Calculator.py
   ```
