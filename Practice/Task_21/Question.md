Problem: A computer shop stores product records as tuples. Each tuple contains the product name, price in rupees, and quantity in stock.

Products = [
("Keyboard", 2500, 10),
("Mouse", 1200, 15),
("Monitor", 25000, 5),
("Headphones", 3500, 8),
("USB Drive", 1500, 20)
]

Requirements:

• Display product records: Use a for loop to unpack each tuple and print the product name, price, and quantity.

• Calculate stock value: Calculate the total stock value of each product using price × quantity. Also calculate the total value of all products in the shop.

• Search for a product: Ask the user to enter a product name. Check whether the product exists in the list and display its price and available quantity. Print "Product not found" if 
it does not exist.
