# 🐍 Python Learning Notes

Welcome to my Python learning repository! This repo contains my personal notes, explanations, and code examples as I learn Python from scratch.

> **Course Reference:** These notes are based on the Python series from [**Chai aur Code**](https://www.youtube.com/@chaiaurcode) on YouTube.
>
> *Note: This repository is currently in progress and gets updated regularly as I cover new topics.*

## 📚 What's Inside

* **Data Types & Memory Management:** Core data types, mutability, reference counting, garbage collection, shallow vs. deep copy, `==` vs. `is`, and `repr()` vs. `str()`.

* **Numbers, Sets & Strings:** `random` module, `Decimal`, `Fraction`, set operations, string slicing, and formatting methods.

* **Lists, Dictionaries & Tuples:** Slice assignment, list & dictionary comprehensions, nested dictionaries, `dict.fromkeys()`, and tuple unpacking.

* **Loops Behind the Scenes:** Iteration protocol (`iter()`, `__next__()`, `StopIteration`) and how iterables differ from iterators.

* **Functions, Scopes & Closures:** Parameters vs. arguments, `*args` & `**kwargs`, `lambda` functions, `yield` generators, recursion, LEGB scope rule, and closures.

* **Built-in Functions:** Quick reference with practical examples of commonly used Python built-in functions.
